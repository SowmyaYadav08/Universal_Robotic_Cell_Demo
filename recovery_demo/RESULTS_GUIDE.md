# Results guide

| Name shown | What it contains | Existing file |
| --- | --- | --- |
| Assembly Recovery Monitor | Priorities, status, issue filters and charts for synthetic scenarios | outputs/dashboard.html |
| Assembly Video Findings | Motion alerts and evidence from the approved recordings | outputs/real_video_review/review.html |
| Recovery Decision Report | Outcome of replaying a video alert through simulated recovery checks | outputs/video_alert_replay/replay.html |
| Plate Replacement Playback | Animation of replacement pickup and stacked mounting; simulated | outputs/recovery_playback.html or outputs/video_alert_replay/recovery_playback.html |
| Assembly Event Log (CSV) | All synthetic scenario events, including checks and outcomes | outputs/events.csv |
| Scenario Results (JSON) | Synthetic inputs and results for all scenarios | outputs/results.json |
| Video Alert Log (CSV) | Unconfirmed motion alerts from approved footage | outputs/real_video_review/review_events.csv |
| Video Review Measurements (JSON) | Thresholds, tracking coverage and alert details | outputs/real_video_review/review_summary.json |
| Recovery Event Log (CSV) | Real-alert trigger and separately labeled simulated recovery events | outputs/video_alert_replay/events.csv |
| Recovery Replay Result (JSON) | Inputs and outcome of one recovery replay | outputs/video_alert_replay/replay_result.json |
| Detection Evaluation Summary (JSON) | Comparison with verified intervals, or a waiting-for-review status | outputs/real_video_review/evaluation.json, if generated |

Chart names: **Priority Overview**, **Defect Breakdown**, and **Scenario Breakdown**.

Outcome labels: **Assembly Completed**, **Replacement Completed**,
**Manual Action Required**, and **Completed — Follow-up Needed**.
Priority remains High/Medium/Low; status remains Open/Resolved. Neither is an outcome label.

File names and machine-readable fields are unchanged. These names describe what
each artifact contains; they do not imply validated detection or physical robot control.

**Process Timing Log (CSV):** outputs/timings.csv, generated by run_demo.py. Simulated elapsed process, pause, recovery, and hold timings; not measured factory downtime.

**Plate Replacement Playback (MP4):** outputs/video_alert_replay/plate_replacement.mp4. Generate with python recovery_demo/export_recovery_mp4.py. Labeled synthetic animation, not real robot recovery footage.
